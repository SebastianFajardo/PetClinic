# PetClinic Cloud

Plataforma web para apoyar la gestión clínica, administrativa y logística de clínicas y consultorios veterinarios.

## Stack

- Backend: NestJS, TypeScript y Domain-Driven Design
- Frontend: React y TypeScript
- Database: PostgreSQL

## Project status

Initial repository setup. Implementation will be developed in the `develop/petclinic-cloud` branch.
